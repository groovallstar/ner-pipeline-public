# 한국어 엔티티 라벨링 규칙 (KO Entity Labeling Rules)

한국어 NER gold 의 LOC/ORG/시설 경계 라벨링 **단일 규칙 출처**. 다국어 공용
`canonical-entity-schema.md`(JA·VI·KO·EN)와 **별개로 관리**한다 — 한국어는 LOC/ORG
외연을 좁게 재정의하며, 공용 스키마의 "인공 시설=전부 ORG"(JA·VI)와 다르다.
이 문서는 사람 주석·dual-LLM 재라벨 양쪽의 rubric 으로 쓴다.

## 핵심 원칙 (한 줄)

> **자연·행정 지리 = LOC · 정부·행정·공공·정치 기관 = ORG · 그 외 전부 = drop**
> (인공 시설·venue + 민간 회사·언론·스포츠·군·법원·종교 조직 = 비-entity,
> + 환유 정부건물명 소수 allowlist 는 ORG)

라벨은 **표면형 어원이 아니라 지시체 종류**로 결정한다 — 같은 종류의 지시체는
항상 같은 라벨을 받는다(일관성 최우선).

## 타입 정의 (평면)

| 타입 | 정의 | 예시 |
|---|---|---|
| **LOC** | 행정구역·정착지·국가·대륙 + 자연지명(산·강·바다·섬·호수·화산) + 주소(도로명·번지). 지명 표면형은 구단·대표팀·환유로 쓰여도 LOC | 서울시·강남구·한국·아시아·한강·백두산·독도·테헤란로152 |
| **ORG** | **정부·행정·공공·정치 기관만** — 부·처·청·위원회·정당·노조·공공기관·공기업·국제기구·의회·정치조직 + 환유 정부건물명 allowlist | 교육부·국세청·선거관리위원회·새누리당·민노총·한수원·유엔·국회·청와대 |
| **drop(비-entity)** | ① 인공 시설·venue·건조물 ② 정부·정치 기관이 아닌 조직(민간 회사·은행·언론/방송·스포츠 구단/리그·군·법원/검찰·종교조직) | 서울역·인천공항·서울대학교·잠실야구장·영동고속도로·삼성전자·KBS·대법원·두산 베어스·한국군 |

EVT·PER·PROD·DAT·PII 는 **정의 불변** — 이 문서 범위 밖.

## 결정 세부

### ① 순수 venue → drop

역·공항·경기장·구장·공원·극장·궁·빌딩·타워·전망대·휴게소 등 **방문하는 인공
시설**은 비-entity 로 drop. gold 가 이미 LOC 로 기울던 것(역·공항·경기장)을
LOC 에서도 빼 완전히 추출 대상에서 제외한다.

### ② 기관 성격 시설 → drop (aggressive)

대학·병원·학교·센터·미술관·박물관·도서관·교회·성당처럼 **운영 조직이 딸린
시설도 예외 없이 drop**. 서울대학교·삼성서울병원도 drop — "운영기관을 지칭하면
ORG" 예외를 두지 않는다. 판정을 0 으로 만드는 가장 well-posed 한 선택.

### ③ ORG = 정부·행정·공공·정치 기관만

물리 실체 없는 조직이라도 **정부·행정·공공·정치성**이 없으면 ORG 가 아니다.
ORG 인 것: 정부 부처(교육부·통일부)·청(국세청·경찰청)·위원회(선관위·공정거래
위원회)·정당(새누리당·진보당)·노동조합(민노총)·공공기관·공기업(한수원·
한국전력공사·국민연금공단)·국제기구(유엔·나토)·의회(국회)·정치조직.

**ORG 아닌 조직 → drop**: 민간 회사·기업·은행(삼성전자·부산저축은행)·언론/방송/
통신사(KBS·엠비씨·AFP통신)·스포츠 구단/리그(두산 베어스·프리미어리그·LPGA)·
군·군부대·사령부(한국군·오산공군기지)·법원·검찰(대법원·수원지법)·종교 조직
(구원파). 근거: 인간 감사에서 사용자 실제 ORG 외연이 정부·정치로 확인됨
(broad-ORG 감사 precision 0.50 → narrow-ORG 1.00).

경계: 정부기관 '청'=ORG(경찰청·국세청) / 시설 '서·소'=drop(경찰서·소방서).
"정부"(정부 조직 환유)는 ORG이나 "경찰"·"군" 단독(제복 인력·조직)은 drop —
기관명 "경찰청"만 ORG.

### ④ 환유 건물명 → ORG (allowlist)

물리적으로는 건물이지만 **행정부·입법부 등 특정 정부 조직을 환유**하는 소수
고유명은 ORG 예외로 유지한다. 열거 가능한 allowlist 로 처리해 판정 재발을 막는다.

allowlist(초기): **청와대·백악관·정부청사·국회의사당(환유 시)·크렘린·펜타곤**.
(국회·의회처럼 조직어 자체는 ③ ORG 정의로 자연히 ORG — allowlist 불필요.)

근거: "청와대는 입장을 밝혔다"는 정부 행위주체이지 방문 장소가 아니다. 같은
정부 행위주체를 이름 어원(건물어 vs 조직어)만으로 가르면 오히려 비일관.

### ⑤ 자연지명·주소 → LOC / 인프라 구조물 → drop

- 산·강·바다·섬·호수·대륙 등 **인공물이 아닌 지리적 위치**는 LOC. `한강=LOC
  (자연 지물) / 한강공원=drop(인공 venue)`.
- **교통 구조물**(고속도로·다리·항구·철도노선): 인공 건조물이라 drop.
- **주소**(도로명·번지): 순수 위치지시라 LOC. `테헤란로 152` → LOC.
- 미세 경계: `세종대로`처럼 주소 도로 ↔ 교통 간선 겸용 표면형은 per-instance.

### ⑥ 지명 표면형은 팀·환유여도 LOC

국가·도시·지역명이 대표팀·구단·환유로 쓰여도 **표면형이 지명이면 LOC**.
`"한국이 승점 4"`도 한국=LOC, 아우크스부르크(도시=구단명)=LOC. 지명이 아닌
팀명(롯데자이언츠)은 ③에 따라 drop. 복합 지명+시설은 지명만 LOC, 시설 버림
(`"서울 명동성당"` → 「서울명동」 LOC + 성당 버림).

### ⑦ EVT — 이 문서 범위 밖 (정본은 canonical §3.3·§5.3)

지속 운영 스포츠 리그·구단은 ORG 가 아니라 drop(민간 조직), 특정 회차 대회·경기만 EVT.

회의·회담·회견·의식은 **bare 여도 EVT** 다 — `정상회담` 은 canonical §5.3 축2 행,
`국무회의`·`기자회견`·`청문회`·`본회의`·`시상식` 등은 같은 표의 R2a~R2c 행이 정한다.
이 문서의 옛 판이 "정상회담·국무회의는 *이미* EVT 이며
손대지 않는다"고 적었으나 gold 실측은 달랐다(`국무회의` EVT 3 / ORG 1 / 무라벨 4). ORG 로
새는 회의체를 여기서 drop 하기 전에 EVT 후보인지 먼저 본다.

## 회색지대 판정 (per-instance)

접미사만으로 안 갈리는 소수는 문맥 지배독해로 판정한다:

| 표면형 | 판정 축 |
|---|---|
| **청/서** | 정부기관 '청'=ORG(국세청) / 시설 '서·소'=drop(경찰서·소방서) |
| **원(院)** | 病院·大學院=drop(시설) / 法院=drop(사법기관) / 政府 공공 研究院=ORG(공공기관) |
| **관(館)** | 博物館·美術館·圖書館=drop(시설) / 환유 정부건물명 allowlist(백악관)=ORG |
| **센터·연수원** | 정부·공공 조직=ORG(대테러센터·사법연수원) / 민간·venue=drop(콜센터·아트센터·기업연수원) |
| **공사/공단** | 公社·公團 공기업=ORG(한국전력공사) / 工團 산업단지(개성공단)=LOC / 민간 항공사·시공사=drop |
| **세종대로류** | 주소 맥락=LOC / 교통 간선 맥락=drop |

## 적용 (dual-LLM 전수 재라벨)

원본 gold 의 모든 LOC/ORG/시설 인스턴스를 이 rubric 을 프롬프트로 주입한
dual-LLM(독립 2모델, temperature 0)으로 재판정한다. **합의분만** 반영하고
불일치는 HOLD→제거(stale 유지 금지). dual-LLM 은 "이 규칙의 전수 적용기"이지
자유 판정자가 아니다. held-out 인간 감사로 재라벨 품질(precision/recall)을
보고한다. 상세·측정: `docs/issues/issue-153-ko-loc-org-facility-schema.md`.
