# 신규 저장소용 CLAUDE.md 스니펫

이 파일은 새 GitHub 저장소를 만들 때 해당 저장소의 `CLAUDE.md`(또는 하위 `src/CLAUDE.md`, `docker/CLAUDE.md`)로 복사·붙여넣어 쓰는 **재사용 규칙 모음**이다.

사용법: 아래 각 섹션을 새 저장소의 적절한 CLAUDE.md에 복사한다.

---

## [코드 영역용] Python 코딩 컨벤션

> 복사 위치: 새 저장소의 `CLAUDE.md` 또는 `src/CLAUDE.md` 내 "코딩 컨벤션" 섹션.

- 문자열 리터럴은 **홑따옴표(`'`)** 를 기본으로 쓴다 (escape 필요 시 `"` 허용)
- 한 줄은 **79자 이내**로 유지 (초과 시 줄바꿈으로 가독성 확보)
- 메서드·함수 사이는 **한 줄만 비운다** (연속 빈 줄 금지)
- Trailing whitespace 제거

---

## [Docker 영역용] 이미지 Pull 규칙

> 복사 위치: 새 저장소의 `docker/CLAUDE.md` (또는 도커를 쓰는 저장소의 `CLAUDE.md`).

- `:latest` 태그 사용 금지. 항상 명시된 버전 태그로 pin 한다 (예: `python:3.12.7-slim`, `pytorch/pytorch:2.11.0-cuda13.0-cudnn9-devel`).
- 최신 이미지를 받아야 할 때는 Docker Hub/GHCR에서 **최신 안정 버전 태그를 확인한 뒤 그 버전을 명시**한다.
- 이유: `:latest`는 빌드 재현성을 깨고, 무인지 업그레이드로 회귀·환경 불일치를 유발한다.

---

## 유지 관리

- 이 스니펫은 본 저장소가 **단일 출처**다. 다른 저장소에 퍼진 사본과 규칙이 어긋나면 이 파일을 기준으로 맞춘다.
- 규칙을 추가/수정할 때는 여기서 먼저 고치고, 필요한 저장소로 전파한다.
