# Wiki Schema

이 문서는 `docs/` 디렉토리의 구조와 운영 규칙을 정의한다.

## 디렉토리 구조

```
docs/
├── schema.md                      # 이 문서 (위키 규칙)
├── wiki/                          # 프로젝트 독립적 도메인 지식
│   ├── concepts/                  # 개념 페이지 (이론, 방법론, 전략)
│   ├── entities/                  # 엔티티 페이지 (구체적 대상)
│   │   ├── datasets/              # 데이터셋별 분석
│   │   └── languages/             # 언어별 NER 방법론
│   └── sources/                   # 원문 소스 (논문, 기사, 실험 기록)
├── api/                           # 코드 종속 API 레퍼런스
└── guides/                        # 프로젝트 종속 실행 가이드
```

## 페이지 유형

| 유형 | 위치 | 설명 | 예시 |
|------|------|------|------|
| **개념** | `wiki/concepts/` | 프로젝트와 독립적인 이론/방법론 | BIO 태깅, 토큰 관리 전략 |
| **엔티티** | `wiki/entities/` | 구체적 대상(데이터셋, 언어, 모델)의 분석 | KLUE NER, 한국어 NER |
| **소스** | `wiki/sources/` | 참고한 원문(논문, 기사)의 요약 | - |
| **API** | `api/` | 코드 모듈의 공개 인터페이스 문서 | bio_dataset, span_evaluator |
| **가이드** | `guides/` | 특정 작업의 실행 절차 | 파이프라인 재구축 |

## 운영 규칙

### 인제스트 (새 지식 추가)
1. 새 소스를 읽고 핵심을 추출한다
2. 기존 위키 페이지에 통합할 수 있으면 기존 페이지를 업데이트한다
3. 새 개념/엔티티면 새 페이지를 생성한다
4. 관련 페이지 간 교차 참조를 추가한다

### 쿼리 (지식 조회)
- 위키 페이지를 기반으로 답변하고, 출처 페이지를 인용한다

### 린트 (품질 유지)
- 코드 변경 후 `api/` 문서가 최신인지 확인한다
- 교차 참조가 깨지지 않았는지 점검한다
- 모순되는 내용이 있으면 표시한다

## 교차 참조 규칙
- 문서 간 참조는 `docs/` 기준 상대 경로를 사용한다
- 예: `` `docs/wiki/concepts/bio-tagging.md` ``
