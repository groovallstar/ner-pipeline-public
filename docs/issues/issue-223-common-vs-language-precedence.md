## 배경 (왜)

canonical 은 `(공통)` 절과 언어별 절을 함께 두면서 **둘이 부딪힐 때 어느 쪽이 이기는지를
정해 두지 않았다.** 오히려 §2.2 가 반대로 읽히는 문장을 갖고 있었다 — "이 표는 폴백이다 —
§3 이후가 정한 개별 규칙이 있으면 그쪽이 이긴다". KO 의 narrow-ORG 는 §2.5 에 사니, 이
문장을 글자대로 읽으면 §2 안의 §2.5 가 §3 의 `(공통)` 항들에 진다.

그리고 §3 은 실제로 KO gold 와 어긋났다. §3 의 여덟 항 중 `ORG` 를 판정하는 것은 넷인데
언어 적용범위가 적힌 것은 인프라 항 하나뿐이었고, 나머지 셋 중 둘이 gold 와 정면으로
갈렸다. 실제 라벨은 §2.5 를 따르지만 **§3 만 읽으면 반대 결론이 나온다** — 라벨러 프롬프트를
고치는 사람도, 새 언어를 붙이는 사람도 §3 을 근거로 삼을 수 있다.

## 목적

canonical 안에서 `(공통)` 선언과 언어별 절의 관계를 명시해, 두 절이 부딪힐 때 답이 하나로
정해지게 한다. `프리미어리그`·`KBS` 가 §3 만 읽어도 KO 에서 `ORG` 로 읽히지 않는 것이
도달 상태다.

## 범위

- 포함: §2.2 폴백 문장의 사정거리 · §3 의 `ORG` 판정 항 언어 적용범위 · 절 참조 무결성
- 제외: **판정 자체는 안 바꾼다.** gold·라벨러 프롬프트·canonical §2.5·§5.3 본문을 안 건드린다
- 제외: §3 의 `PROD`·`EVT` 판정 항 (§3.4·§3.3 소관)
- 제외: §2.3 JA 행 이동 · §4.3 EN 자기모순 · `mapping.py` 주석 — 아래 결정 로그 참조

## 현 상태 (fact)

`data/klue/origin.jsonl` 25,989 행 실측. 세 갈래 모두 §2.5 판정과 같은 방향이다.

| 표면형 갈래 | 등장 / 라벨 |
|---|---|
| 스포츠 리그·구단 | `프리미어리그` 17 / 0 · `두산 베어스` 2 / 0 · `LPGA` 5 / 0 |
| 언론·방송 약어 | `KBS` 79 / 0 · `SBS` 68 / 0 · `JTBC` 27 / 0 · `YTN` 9 / 0 |
| 국제기구·정부기관 약어 | `EU` 13 / 13 `ORG` · `OECD` 8 / 8 `ORG` · `FIFA` 14 / 11 `ORG` |
| 기타 약어 | `KTX` → `PROD` · `NLL`·`DMZ` → `LOC` · `AOA`·`EXO` → `PER` |

**읽는 법** — KO 는 약어를 지시체 종류로 가른다. §3 의 "시그널 부재 시 `ORG` 우선" 이라는
**기본값이 KO 에 없는** 것이지 KO 가 약어를 안 뽑는 것이 아니다. 그래서 약어 항의 KO
마커는 배제형이 아니라 §2.5 를 가리키는 포인터형이다.

절 참조는 착수 시점에 canonical·`src/` 양쪽 모두 실재 절을 가리켰다. A5 는 회귀 그물이다.

## 구현 결과

**canonical** — 머리말 뒤에 `절 우선순위` 를 세워 언어별 절이 `(공통)` 절을 이긴다는 것과
적용 마커의 뜻을 적었다. §2.2 의 폴백 문장은 `(공통)` 층 안으로 사정거리를 좁히고, 그
문장을 "§2.5 가 §3 에 진다" 로 읽으면 KO narrow-ORG 가 뒤집힌다는 것을 덧붙였다. §3 의
`ORG` 판정 항 넷에 마커를 달았다 — 리그·팀·인프라·약어 단독은 `적용: JA·VI·EN · KO 는
§2.5`, 동음이의 가타카나 단독은 `적용: JA` 다. §3.2 표의 `회사·사업체·레코드 레이블` 행과
§3.3 보조원칙의 `운영리그 vs 경기` 항도 같은 마커를 받았다 — 소절이라고 빼면 머리말의 전칭이
거짓이 되고, 뒤엣것은 `프리미어리그` 를 `ORG` 로 재진술하는 자리라 이 이슈의 목적이 그대로
새어나간다.

**테스트** — `test_canonical_scope_markers.py` 가 §3 을 파싱해 `ORG` 판정 자리마다 마커가
있는지, 그 머리·스코프가 테스트 모듈 상수와 같은지 본다. 모집단은 최상위 불릿이 아니라 다음
`## ` 까지의 §3 전체이고 소절의 표 행도 판정 단위로 읽는다 — 소절에서 멈추면 새 `ORG` 판정을
아무 소절에나 써서 마커 없이 통과시킬 수 있다. 기대 목록을 canonical 에서 읽지
않는 것은 그러면 canonical↔canonical 자기대조가 되어 마커와 판정을 같은 커밋에서 함께
고칠 때 무엇을 적든 초록이기 때문이다. `test_canonical_section_refs.py` 는 canonical 과
`src/` 의 모든 `§N`·`§N.M` 이 실재 절을 가리키는지 본다.
