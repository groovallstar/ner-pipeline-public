# 이슈 문서 작업 지침

문서 역할·배치와 공통 작성 기준은 상위 [문서 작업 지침](../AGENTS.md)을 따른다.
GitHub Issue는 작업 접수·협업·상태와 관련 변경을 연결하는 데 사용한다.

## Codex 작업 기록

- 이슈 생성 여부는 루트의 작업 절차에 따라 판단한다.
- 같은 목표의 작업은 기존 이슈 문서를 재사용한다. 승인된 spec이 있으면 관련 요구사항을
  연결하여 재사용하고, 별도 계획서나 승인 원장을 중복 생성하지 않는다.
- 요구사항은 이슈 본문뿐 아니라 최신 사용자 요청과 기존 결정을 함께 반영한다.
- 변경 전에 배경·목표, 포함·제외 범위와 제약, 완료 기준과 확인 방법을 기록한다.
  필요한 테스트와 문서 영향도 포함한다. 기준을 정하기 위한 조사·질의는 먼저 진행할 수 있다.
- 현재 상태와 계획·미해결 질문을 구분한다. 결정이 바뀌면 이전·새 결정과 이유,
  미루거나 포기한 목표를 남기고 현재 기준을 갱신한다. 과거 결정의 이력은 보존한다.
- 진행 과정은 주요 결정과 필요한 근거 중심으로 기록한다. 명령·대화·실험 로그 전체를
  옮기지 않으며, 검증 명령·실행 조건·결과·근거 위치와 미검증 범위를 남긴다.
- 관련 코드·문서·커밋·후속 작업을 연결한다. 작업 완료와 커밋·원격 반영 여부를 구분하며,
  오래된 GitHub 이슈 내용을 현재 결정으로 취급하지 않는다.

## GitHub 이슈 절차와 양식

1. 요청·증상·관련 코드로 기존 이슈를 확인하고, 없으면 작업 요약으로 생성한다.
   기존 이슈를 이어갈 때는 연결된 작업 문서의 현재 상태와 결정을 확인한다.
2. 이슈와 동일한 제목으로 작업 문서를 만들거나 기존 문서를 갱신한다.
   파일명은 `issue-{번호}-{슬러그}.md`로 정한다.
   변경 전에 위 작업 기록 기준을 반영한다.
3. 문서를 커밋·푸시하여 원격에서 접근할 수 있게 되면 이슈에 문서 링크를 추가한다.
   게시 전에는 문서 경로와 게시 대기 상태를 표시하고, 승인된 로컬 작업은 계속할 수 있다.
4. 진행 과정·주요 결정·검증 결과는 문서에 갱신한다. 댓글에서 채택한 결정과 이유도
   문서에 반영하며, 상세 내용과 체크리스트를 두 곳에 중복 유지하지 않는다.
5. 각 완료 기준에 충족 여부와 검증 근거를 기록한다. 테스트 통과만으로 모든 요구사항이
   완료됐다고 판단하지 않으며, 실패·미검증·미충족 항목은 남은 작업으로 구분한다.
6. 이슈에는 결과 요약·문서 링크·관련 커밋이나 PR·남은 작업을 반영한다. 미완료 작업은
   열린 상태로 유지한다. 취소하거나 다른 작업으로 대체하면 그 결정과 이유를 남기고 종료한다.
   문서 링크는 원격에서 접근 가능해지는 시점에 추가하며, 종료 시점까지 미루지 않는다.

커밋·푸시와 GitHub 쓰기는 기존 사용자 승인 범위에 따라 수행한다.
문서 작성 자체가 외부 게시 권한을 대신하지 않는다.

웹 폼과 CLI·API 모두 아래 양식을 따른다. 생성 시 작업 요약만 필수이며,
나머지는 내용이 생길 때 추가한다. 웹 폼은 `.github/ISSUE_TEMPLATE/task.yml`에 있다.

```markdown
## 작업 요약

이 작업이 필요한 이유와 달성하려는 결과를 간단히 작성한다.

## 작업 문서

- 문서: [작업 제목](문서 링크)

## 관련 변경

- PR:
- 주요 커밋:

## 종료 요약

- 결과:
- 남은 작업:
```

## 작업 문서 구성

작업별 Markdown 한 파일에 현재 기준과 이력을 함께 유지한다.
다음 항목을 기본으로 사용하되, 제목과 구분은 작업 성격에 맞게 조정한다.
아직 내용이 없는 결과 항목은 작업이 진행되면 채운다.

- 배경·목표: 왜 필요한지와 달성하려는 결과를 기록한다.
- 범위·제약: 포함·제외 범위와 지켜야 할 조건을 기록한다.
- 완료 기준: 무엇을 어떻게 확인할지 기록한다.
- 현재 상태: 진행 상황·다음 작업·미해결 질문을 구분한다.
- 결정 이력: 주요 선택과 변경 이유를 기록한다.
- 결과·검증: 변경 내용·검증 근거·미검증 범위·남은 작업을 기록한다.
- 관련 자료(선택): 필요하다면 절을 두고 코드·문서·이슈·PR·커밋을 연결한다.
