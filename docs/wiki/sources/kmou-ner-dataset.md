## 핵심 요지

한국어 형태소 단위 NER 데이터셋. 형태소 분석 결과를 토큰 축으로 삼아 BIO 태깅을 적용한다. 표준 BIO와 달리 **`I` 단독 태그**(타입 미포함)가 등장하며 직전 `B_<T>` 태그의 타입을 상속하는 **비표준 스킴**을 사용한다.

## 태그 스킴 (본 프로젝트 관점)

- 구분자가 `-`가 아닌 `_` (예: `B_PS`, `B_LC`)
- `I` 태그가 단독으로 등장 → "직전 활성 타입 상속"으로 해석해야 함
- 따라서 표준 변환기(`extract_spans_from_bio`) 적용 전 **로더에서 `I → I-<직전 B의 타입>`으로 치환하는 전처리**가 필요.

자세한 처리 절차: `concepts/bio-tagging.md` §4.4.

## 토큰화 특성

- **형태소 단위(morph-level)**: 의미 최소 단위로 분리 (조사·어미 분리됨).
- 원문 복원 시 형태소 사이 공백이 원문과 일치하지 않을 수 있어, 엄격한 character offset 매칭이 필요한 경우 재정렬 단계 추가 필요.
