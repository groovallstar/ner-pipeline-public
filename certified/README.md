# 과거 실험 결과 보관

이 디렉터리의 JSON은 과거 문서가 인용한 실험 결과를 보존하는 자료다.
출처는 `/work/git/ner-pipeline`의 `6c7a64f` 작업 트리이며 바이트 그대로 복사했다.
파일 안의 실행 조건과 대응하는 이슈·리포트로 당시 출처를 확인할 수 있다.

현재 테스트·배포·하네스는 이 디렉터리를 검증 기준으로 사용하지 않는다.
새 결과의 승격이나 출처 선언 관리도 수행하지 않는다. 새 실험 결과를
문서에 인용할 때는 루트 AGENTS.md의 일반 출처·실행 조건 기록 원칙을 따른다.

## 사용 종료 결정

- 이전에는 문서 출처 선언의 존재·경계, 영어 배포 결과의 실험 조건,
  한국어 과거 결과의 표본 수를 이 디렉터리와 대조했다.
- 사용자 요청에 따라 해당 검증과 선언 관리를 종료한다. 기존 JSON과 문서의
  수치는 과거 기록으로 보존하며, 이 디렉터리에 대한 자동 대조는 유지하지 않는다.
- 성공 기준은 코드·테스트의 디렉터리 의존성과 자동 출처 선언이 없어지고,
  일반 배포 패키지 검사와 라벨 감사가 유지되는 것이다.
- 검증은 관련 테스트, Ruff, 남은 참조 검색 및 최종 코드 리뷰로 수행한다.

검증 결과: `uv run pytest tests/ner/classifier/test_en_deploy_package.py
 tests/ner/labelers/test_ko_evt_holiday_audit.py -q -m 'not integration'`에서
59개가 통과했고 모델 로드 통합 테스트 1개는 선택 대상에서 제외했다.
두 테스트 파일의 Ruff 검사와 `git diff --check`도 통과했다.
전체 테스트와 모델 로드 통합 테스트는 실행하지 않았다.
